# Changelog

## 2026-10-29 — DuckBoard 1.1

- First-run setup wizard now uses the duck mark, states the privacy promise and
  includes a test field.
- Removed `READ_CONTACTS` and the contact-name dictionary UI. DuckBoard now
  requests no dangerous permissions.
- Version bumped to 1.1 (`versionCode 7`); no change to the signing key.

## 2026-10-25 — DuckBoard 1.0

First DuckBoard release, based on HeliBoard 4.3-beta1.

- DuckBoard identity, package `com.cristifcp.duckboard`, and matching providers.
- Duck Night and Duck Paper themes with Duck Reader's cream/teal/amber palette.
- Rounded, filled keys by default; numbers 1–0 as top-right hints on the QWERTY row; emoji key in the bottom row.
- New cheerful duck-and-keyboard launcher icon, padded so launchers do not crop it.
- Clipboard history off by default; turn it on in Clipboard settings when wanted.
- Android backup and device transfer disabled; still no INTERNET permission.
- Romanian dictionary kept in debug builds.
- Real-device screenshots and a DuckBoard README/modification notice.
