# Modifications

DuckBoard is a fork of [HeliBoard](https://github.com/HeliBorg/HeliBoard), which is
licensed under the GNU General Public License v3.0. DuckBoard is licensed under
the same terms. This file exists to satisfy GPLv3 § 5(a): it states that the work
was modified, and gives the dates.

Upstream: `HeliBorg/HeliBoard`, branched from `main` at `4.3-beta1`
(`versionCode 4300`). DuckBoard first built: 2026-10-25.

## Identity

| Change | Where |
|---|---|
| Application label, IME name, settings title, spell-checker service name: "HeliBoard" → "DuckBoard" | `app/src/main/res/values*/` (262 lines across 64 files, via `scripts/rebrand-brand.ps1`) |
| `applicationId` → `com.cristifcp.duckboard` | `app/build.gradle.kts` |
| APK output name prefix → `DuckBoard_` | `app/build.gradle.kts` |
| Content-provider authorities → `com.cristifcp.duckboard.{clipprovider,provider}` | `app/src/main/res/values/clip_provider.xml`, `gesture_data.xml`, and the `app/src/debug/res/values/` copies |
| Repository links in About → DuckBoard | `app/.../latin/common/Constants.kt` |
| About fork notice names HeliBoard and DuckBoard | `app/src/main/res/values/strings.xml` |
| Launcher icon: cheerful duck-and-keyboard artwork, adaptive + legacy + round | `mipmap-*/ic_launcher*.png`, `drawable-*/ic_launcher_foreground.png`, `drawable-v24/ic_launcher_background.xml`, generated by `tools/generate_brand.py` from `branding/duckboard-icon.png` |
| Build identity fields `DUCKBOARD_BUILD` / `DUCKBOARD_COMMIT` | `app/build.gradle.kts`, `app/.../settings/screens/AboutScreen.kt` |

The Java/Kotlin package (`helium314.keyboard.*`) is deliberately unchanged: it is
not user-visible, it would touch every file, and renaming it would make each
upstream merge a conflict. The `applicationId` is the identity that matters.

## Look and defaults

| Change | Where |
|---|---|
| **Duck Night** theme: deep teal-black keyboard, dark green keys, cream text, amber accent and gesture trail | `app/.../keyboard/KeyboardTheme.kt` (`THEME_DUCK_NIGHT`) |
| **Duck Paper** theme: warm cream keyboard, white keys, tan functional keys, amber accent | `app/.../keyboard/KeyboardTheme.kt` (`THEME_DUCK_PAPER`) |
| Duck Night is the night default, Duck Paper the day default | `app/.../latin/settings/Defaults.kt` |
| Default style **Rounded** with key borders, so keys are filled instead of transparent | `app/.../latin/settings/Defaults.kt` |
| Emoji key in the bottom row by default | `app/.../latin/settings/Defaults.kt` (`PREF_SHOW_EMOJI_KEY`) |
| Key hints off by default (Gboard-like clean keys) | `app/.../latin/settings/Defaults.kt` (`PREF_SHOW_HINTS`) |
| Romanian dictionary no longer stripped from debug builds | `app/build.gradle.kts` |

## Privacy

| Change | Where |
|---|---|
| Clipboard history off by default | `app/.../latin/settings/Defaults.kt` (`PREF_ENABLE_CLIPBOARD_HISTORY`) |
| Android backup and device transfer disabled; learned words and clipboard history stay on the device | `app/src/main/AndroidManifest.xml`, `app/src/main/res/xml/data_extraction_rules.xml` |

## Not changed

- `LICENSE` — untouched, GPL-3.0.
- Copyright headers and author credits — untouched, including upstream issue
  links in comments, which keep pointing at `HeliBorg/HeliBoard` on purpose.
- No network code was added and no permission was requested. DuckBoard keeps the
  defining property of upstream: no `INTERNET` permission.
- Any behaviour, default, or setting not listed above.

## Rebranding after an upstream merge

The fork brand appears in 250+ string resources across every locale. Re-run:

```powershell
./scripts/rebrand-brand.ps1 -Old HeliBoard -New DuckBoard -WhatIf
./scripts/rebrand-brand.ps1 -Old HeliBoard -New DuckBoard
```

Lines containing a URL are skipped, so attribution links survive.
